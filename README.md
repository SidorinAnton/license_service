# Сервис активаций лицензий

Цель: необходимо реализовать MVP сервиса активаций лицензий.

## Архитектура

img!!!

0. Заранее генерируем публичный и приватный ключ -- на клиенте публичный, на сервере -- приватный
1. Запускаем клиента на устройстве
   `python src/main.py ABCD-1234-EFGH-5678 https://server`
2. Скрипт собирает информацию об устройстве:
    - os_system -- какая ОС (линукс, винда ...)
    - os_release -- сборка ОС (6.8.0-147-generic)
    - os_version -- версия ОС (#147-Ubuntu SMP PREEMPT_DYNAMIC)
    - cpu_arch -- архитектура процессора (x86_64)
    - cpu_cores -- количество ядер
    - mac_address -- МАС адрес
    - machine_id -- уникальный идентификатор устройства
3. На клиенте генерируем одноразовый синхронный симметричный ключ (`AES-256-GCM`)
   Шифруем им полученные из п.2 данные вместе с лицензией -- `aes-gcm(license_key + data + timestamp)`.
   В результате алгоритма получаем также `Auth Tag`, который по сути можно назвать хеш-суммой.
   Изменение любого бита приведет к невозможности расшифровки
4. Из п.0 на клиенте у нас есть публичный ключ. Им мы шифруем сгенерированный в п.3 симметричный ключ.
   В результате на сервер идет запрос вида `pub(aes-gcm-key) + nonce + данные из п.3`
5. На сервере запрос приходит. В middlware (или как-нибудь еще) происходит дешифрация приватным ключом ключа aes-gcm-key
6. Полученным симметричным ключом (aes-gcm-key) расшифровывем данные
7. Если все норм, имеем данные из п.2 + лицензионный ключ
8. Проверяем формат лицензии, актуальность таймстемпа.
   Делаем запрос в БД. Если лицензия уже есть -- ошибка. Если добавилось -- отвечаем, что все норм.
